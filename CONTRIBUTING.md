# Contributing to Xiaovv Decoder

Bug reports, compatibility reports and feature suggestions are welcome through GitHub Issues.

## Code and documentation contributions

Please do **not** submit source-code or documentation pull requests unless you have first received explicit agreement from the project owner.

Xiaovv Decoder uses a noncommercial public license together with separate commercial licensing. Merging third-party contributions without an appropriate contributor agreement can prevent the project owner from licensing the complete project consistently, including under commercial terms.

If external code contributions are accepted in the future, a separate contributor agreement may be required before a pull request is merged.

Do not submit code, documentation, media or other material that you do not have the right to contribute.
